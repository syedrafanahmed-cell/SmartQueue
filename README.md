SmartQueue – QR-Based Queue Management System

📌 Overview

SmartQueue is a web-based QR Queue Management System that allows users to join a queue by scanning a QR code and submitting a form. The system generates a token and helps administrators manage queue records efficiently.

🚀 Features

* QR Code-Based Registration
* Automatic Token Generation
* Responsive User Interface
* Admin Dashboard
* JSON File Storage
* Real-Time Queue Management

🛠️ Tech Stack

* React.js
* Node.js
* Express.js
* HTML, CSS, JavaScript
* JSON File Processing

⚙️ Workflow

1. Scan QR Code
2. Fill Form
3. Submit Details
4. Receive Token
5. Admin Manages Queue
